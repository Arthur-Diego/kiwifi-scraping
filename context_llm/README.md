# Pasta `context/`

Este diretório contém os documentos de engenharia de contexto do projeto.

## Regras
- Atualize estes arquivos junto com mudanças relevantes no código.
- Toda decisão importante vira um ADR em `07_ADR_DECISIONS.md`.
- Mantenha curto e útil (prefira bullets e exemplos).

## Sugestão de rotina
- Ao iniciar uma feature: revise `02_SCOPE.md` + `11_ROADMAP.md`
- Ao mudar arquitetura/stack: crie/atualize ADR
- Ao mudar chunking/embeddings: atualize `05_RAG_DESIGN.md` e rode avaliação em `09_EVALUATION_TESTING.md`
